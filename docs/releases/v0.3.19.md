## Team messages, without the friction

- Ask naturally to message another open OsmoGrep session, then continue the conversation without repeating session IDs. Agents use live session names and Agent A/B labels, with direct replies routed to the sender.
- Read new messages in a quiet strip above the input. It disappears after seven seconds; Settings → Team keeps the full history, participant session IDs, UTC timestamps and read receipts.
- Open large messages and outputs with Show more / Show less. Expanded file diffs retain every line and report accurate addition/deletion totals.
- Keep message bodies and receipts across restarts, deduplicate retries, and leave messages pending when a recipient model request fails or is cancelled.
- Give the model clearer OsmoGrep identity, task context and communication instructions, with fewer unnecessary tool searches.

Messages remain local to a repository. Idle sessions display incoming messages immediately and consume them on their next model turn; this release does not start automatic idle model calls. A read receipt is not a claim that a teammate completed the work.
