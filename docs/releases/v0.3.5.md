## OsmoGrep 0.3.5

- Start fresh on every launch; reopen saved conversations from Shift+Left while keeping your appearance, shortcuts, and permission profile.
- Work beside an integrated black Neovim editor, with no LazyVim welcome screen. Space a returns to chat; closing the editor expands the agent.
- Find settings through visible categories and read token usage through a compact input/output summary.
- Copy highlighted command blocks with one click, with numbered file diffs and reliable transcript scrolling.
- Keep the approved original working orb, quieter voice status, better input spacing, and session/shortcut hints during longer conversations.

This release also includes natural communication between existing OsmoGrep sessions and the release finder with Update now, Later, and Skip this version.

The expanded model-specific reasoning selector, Ollama Cloud, and vLLM additions are deferred to the next iteration; they are not part of this release.
