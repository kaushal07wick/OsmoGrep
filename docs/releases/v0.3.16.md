## Automatic app workspaces

- Open Mac or iPhone once: missing companions, runtime setup, device creation and boot happen automatically. Existing devices are reused; progress stays beside chat.
- Agents can use `device_workspace` for app development and discover device screenshots, interaction and lifecycle controls through MCP in the same task. Headless setup returns a pollable command session.
- Keep device tools out of greetings, unrelated tasks and read-only sessions. First-time guest account/privacy steps and missing Xcode still report the input they need.
- Remove redundant Setup menu rows and calibrate the Windows test fixture's startup deadline without changing production language-server timeouts.

Device runtimes remain optional and are never downloaded at app startup. Mac and iPhone workspaces require an Apple silicon Mac. The GitHub release also includes the small npm/pnpm launcher tarball.
