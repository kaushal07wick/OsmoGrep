## Chat-first editor workspace

- Keep chat on the left and Neovim on the right in native Ghostty panes, with a compact file tree, live-edit ticker, persistent file tabs and split inspection.
- Open chat immediately with silent update checks. Keep the welcome header through the first exchange; hide it from the second message.
- Keep graphics in their pane, use lean code blocks with orange copy controls, and scroll in smaller steps without a visible scrollbar.
- Clear old diff previews with `/clear` while keeping conversation context, file changes and undo history.

The approved orb artwork is unchanged. Permissions stay inline with clickable decisions. Native editor panes require Ghostty 1.3+ on macOS and Neovim; the tmux fallback remains available for other terminals. Your personal terminal and Neovim settings are not modified.
