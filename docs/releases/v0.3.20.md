## Everyday commands and a shared Doctor

- Use `update`, `models`, `config`, `team` and `completions` from your shell, with terminal-aware help and clearer examples.
- Open `/doctor` or Settings → Doctor for background health checks, deeper diagnostics, safe private-storage repairs and an explicit Ask agent action.
- Keep typing responsive while rendering or processing bursts of agent events. Captured commands no longer inherit terminal keyboard input.
- Collapse long diffs by visual rows, including minified files, and keep Show less reachable while reading expanded output.
- Read older output without being pulled back to the bottom. A compact Latest action resumes live output and marks new activity.
- Open blue-tinted web links with one click. A Personal browser launcher is respected when available.

Existing command names, flags and permission-profile aliases remain compatible. Model discovery makes catalog requests rather than paid generation calls. Doctor's automatic repairs cover application directories and private file permissions; other issues get specific next steps and can be investigated by the model under the current permission policy. This release includes the team messaging and saved Team history improvements from v0.3.19.
