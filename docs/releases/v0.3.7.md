## OsmoGrep 0.3.7

- Transparent provider marks with light and dark variants, replacing boxed avatar images.
- Padded code blocks with a quieter language header and compact copy action.
- Recent sessions appear first, with compact project names and an animated selection dot.
- Ctrl+N creates a new session from the session center without using Mac brightness keys.
- Command+Left opens sessions when forwarded by the terminal; Ctrl+S is available as a fallback.

Ghostty settings remain unchanged. Its default Command+Left binding sends Ctrl+A, so use Ctrl+S there. Shift+Left is available for selecting text again.
