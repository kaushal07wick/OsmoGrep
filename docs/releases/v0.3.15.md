## Optional companions and npm packaging

- Download Mac and iPhone companions from Settings → Workspace when you need them. Progress, checksum checks, signature verification and automatic path configuration are included; device runtimes remain a separate setup step.
- Find built companions when starting in their parent workspace or a nested project.
- Install OsmoGrep with npm or pnpm using the small `osmogrep-npm.tgz` release asset. It fetches the matching Rust binary on first launch and reuses it offline afterward; no install scripts or bundled companion applications.

Mac/iPhone companions require Apple silicon macOS. The npm launcher supports the four existing native release targets. The npm registry short name remains unavailable until registry publication; GitHub tarball installation works without an npm account.
